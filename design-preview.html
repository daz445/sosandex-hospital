8. Доступность

Контрастность (WCAG 2.1 AA)
text primary / bg #0F172A on #FFFFFF = 16.1:1 ✅
text secondary / bg #475569 on #FFFFFF = 7.1:1 ✅
text muted / bg #94A3B8 on #FFFFFF = 3.5:1 — крупный текст ✅
primary btn #FFFFFF on #2563EB = 4.6:1 ✅
danger btn #FFFFFF on #EF4444 = 4.5:1 ✅
Требования
✅ Focus ring: 3px outline на всех интерактивных элементах
✅ Touch target: минимум 44×44px на mobile
✅ Семантический HTML: nav, main, table, form
✅ Label ↔ Input связь через for/id
✅ Статусы не только по цвету — есть текст + точка
✅ Tabular nums для числовых данных
